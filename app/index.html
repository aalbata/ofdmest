Wiener design width and estimator comparison for pilot-aided OFDM

Enter a pilot map, a delay profile and the signal-to-noise ratio (SNR). The page returns the width of the uniform design profile of a Wiener channel estimator from the span rule, and the exact error, SNR loss and achievable rate of the common linear estimators. All values are computed from second-order channel statistics by the ofdmest package. Nothing is simulated.

Inputs

nr:<resource blocks>:<spacing kHz>:<DM-RS type>, lte:<resource blocks>, or custom:<subcarriers>:<spacing Hz>:<FFT size>:<cyclic prefix>

comb:<spacing>:<offset>, centred:<pilots>, anchored:<pilots>, list:<i,j,...>. Leave empty for the standard map of an nr or lte grid.

Width of the uniform design profile (span rule)

Rule: delay spread × ln(SNR / (pilot spacing × delay spread)), minus one resolution cell of the band (an empirical correction), within the limits of the cyclic prefix and of the pilot spacing. The width shown is that of the taps that realize it, the number of taps times the sample period.

Estimators at

Error is the normalized mean squared error over the band. The matched Wiener filter is built on the actual profile and is the best linear estimator. SNR loss and rate treat the estimation error as noise in Rayleigh fading. Multiplications are real multiplications per OFDM symbol.

Setup of this computation

The computation runs in this browser tab. What is entered or chosen here, including a profile file, does not leave the computer. The Python runtime (Pyodide ) is loaded from cdn.jsdelivr.net, and its NumPy and SciPy versions differ from those pinned for the package. The 20 MHz LTE map takes about 13 seconds per SNR value on a laptop, and the run time grows with the number of pilots and subcarriers. The analysis covers one OFDM symbol with a static channel and one antenna. Package ofdmest , MIT License, by Ali Al Bataineh and Lakshmana Kumar Ramasamy, source code and paper results.
